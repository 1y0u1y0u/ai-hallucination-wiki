# 先討論、後生成：可直接貼給 AI 的分階段 Prompt

## Prompt A：先討論，不生成
我準備建立一個關於「生成式 AI 幻覺與事實查核」的 LLM Wiki。受眾是沒有 AI 技術背景的同學。請先和我討論：學習目標、應包含的五個核心概念、五篇來源各負責什麼內容，以及不應誇大的主張。此階段不要產生簡報程式碼。請先給我一個規劃表。

## Prompt B：Ingest 五份來源與概念關聯
請依序 ingest `ingest/` 資料夾中的五份來源閱讀筆記。每份來源請先輸出主要論點、可能的概念頁、與原有頁面有無矛盾，經確認後才更新 Wiki。來源 ID 必須保留 S01–S05；建立五種概念頁並雙向連結。結束後執行 Wiki lint/status，回報確切成功/失敗數量；若工具不可用，明確說明，不得假裝完成。

## Prompt C：只從 Wiki 產生教學大綱
請先讀 Wiki 的 index 與五個 concepts 概念頁，不要直接根據你自己的常識。生成 12–14 頁繁體中文初學者教學簡報大綱，每頁附上 source IDs、對應 Wiki 概念頁與一句學習目標。如有任何頁無法找到 Wiki 支持，標記 NEED_SOURCE，不要編造。

## Prompt D：產生與驗證 HTML
請根據已核對的大綱製作 HTML/CSS/JS 簡報。必須可離線開啟，支援左右鍵翻頁、上一頁/下一頁、頁碼與進度、RWD 和一題互動查核練習；所有事實頁附來源 ID 和外部來源連結。先完成 source-to-slide 對應表，再編寫 UI。檢查每頁 HTML 與按鍵功能，修正後列出實測事項與尚未測試事項，勿虛構測試。

## Prompt E：依檢查結果回修
核對 docs/source-mapping.csv、Wiki、HTML 的每一個知識性主張。若出現不受支持的內容，回到 Wiki query 重做該頁；若只出現 CSS 或鍵盤問題，僅修 UI。請用「發現的問題 → 回到哪個節點 → 修正方式 → 複測結果」記錄一次實際 loop。
