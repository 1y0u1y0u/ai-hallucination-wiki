# S04｜Grounding overview

- **機構**：Google Cloud
- **原始來源**：[Grounding overview](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/grounding/overview)
- **本次輸入**：[S04_google-cloud.md](../../ingest/S04_google-cloud.md)
- **來源性質**：`ingest/` 是中文閱讀筆記，不是原文全文；本頁依該筆記及本次可讀取的官方文件整理。
- **主題**：Grounding、可驗證來源與 RAG

## 主要知識與主張

1. Google Cloud 將 grounding 說明為把模型輸出連接到可驗證資訊來源。
2. 文件指出，提供特定資料來源可使回答依據該資料、降低捏造內容的機會，並藉由來源連結增加可稽核性。
3. 文件列出多種 grounding 方式，其中包括使用檢索增強生成（RAG）連接網站或文件資料。
4. 因此，RAG 是可用來 grounding 的方法之一；不應把兩個名詞當成完全相同的概念。

## 使用界線

「降低捏造機會」不等於保證回答正確。仍須確認檢索到的資料是否可靠、引用是否存在，以及引用是否真的支持回答。
